基础数据审核工具（统信版）内网离线安装说明
============================================

适用：目标机器无法访问外网/软件源（内网机器）。

一、你需要带过去的东西
----------------------
把整个 deb/ 目录拷到内网机（U 盘等），内含：
  - base-audit-uos_1.1.0_amd64.deb        主程序安装包
  - deps/                                  全部依赖(.deb) + 依赖清单.txt
                                            （在本机能连源的机器上用 收集依赖.sh 生成）

二、内网机安装步骤
------------------
1) 先装依赖（在 deps/ 目录里，会按依赖自动排错）：

     cd deps
     sudo dpkg -i *.deb
     # 若提示还有缺的依赖(偶发顺序问题)，再执行一次：
     sudo dpkg -i *.deb
     # 或：sudo apt install -f   (仅当系统源可用时)

2) 装主程序：

     sudo dpkg -i base-audit-uos_1.1.0_amd64.deb

3) 启动：

     开始菜单里点「基础数据审核工具（统信版）」
     或命令行：/usr/bin/base-audit-uos

三、依赖与 LibreOffice 说明
---------------------------
- 本包 Depends: libgtk-3-0, libreoffice-calc, libreoffice-core
- libreoffice 用于“公式校验复制”的公式重算；若不装 LibreOffice，
  公式校验/计算类流程无法运行，但模板/条件格式提取等纯 openpyxl 功能仍可用。
- deps/ 已包含上述依赖及其全部传递依赖，离线可装。
- 若内网机是 V20（本 deps 按 V25 源收集），需在能连 V20 源的机器上
  重新执行 收集依赖.sh 生成 V20 版 deps，不能混用版本源。

四、若运行闪退/无窗口（虚拟显卡环境 VMware/QXL 等）
---------------------------------------------------
启动器已自动检测虚拟显卡并切换软件渲染。若仍异常，可强制软件渲染：
    BASE_AUDIT_FORCE_SOFTWARE=1 /usr/bin/base-audit-uos

五、数据文件（不随程序包安装）
------------------------------
模板、历史审核说明.xlsx、data/ 业务配置为程序外文件，请按业务需要另行放置；
程序首次运行会让你选择模板与源数据目录。
