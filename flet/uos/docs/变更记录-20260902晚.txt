二、条件格式提取 —— 根因与彻底修复（核心）
--------------------------------------------
现象：校验规则能提，但“条件格式结果提取”一直为 0。

根因（两层）：
1) python3-uno 缺失导致整批中止 —— 已解决。
2) 更深层：LibreOffice 的 UNO 读不到条件格式渲染色。
   CellBackColor 只反映基础填充，条件格式是动态叠加，UNO 无 API 可取；
   在 xlsx / LO 重存 / .ods 三种文件上实测均如此（规则在但色恒 -1）。
   Windows/Excel/WPS 能提是因为 COM 的 DisplayFormat.Interior.Color 是专用 API。
   因此“用 LO 渲染色”路线在 LibreOffice 下走不通，已废弃。

修复（uos/src/uos_audit/conditional_format.py）：
- 改为纯 openpyxl OOXML 规则求值：直接读被扫描工作簿自带的条件格式规则，
  判断触发并取规则 dxf 填充色作为渲染色，不再依赖 LibreOffice/uno。
- cellIs 各运算符（=、<>、<、>、<=、>=、between）直接求值。
- expression 公式型新增轻量求值器 evaluate_expression_formula：
  支持 AND/OR/NOT/ABS/SUM、比较与算术、数字/字符串(含"")、单格与 A1:B2 区域、
  $ 绝对/相对锁定；以规则范围左上角为锚点按目标格平移相对引用（与 Excel 一致）。
- dxf 色解析支持 rgb、indexed（COLOR_INDEX，如 indexed=10→红 FFFF0000）、
  theme(前12主题色 + tint)。无色 dxf 不产出。
- 多规则同格按 priority 取后应用色、stopIfTrue 停止（近似 Excel）。

规则编号与描述：
- 规则编号(rule_id) 改为业务约定格式：
    工作簿名(去日期)｜sheet名｜定位单元格｜校验指标
  例如：惠州农村商业银行…_B00__在线核查表｜存量单位贷款信息｜C26｜合计_本期余额
- 描述(detail)：单元格有批注用批注；无批注时还原规则本身：
    cellIs     -> 条件格式规则：C26>0
    expression -> 条件格式规则：d35<>d27+d28+d34（去$、小写、紧凑）

支持范围与边界：
- 被扫描的是源报送文件自带的规则；模板的 expression 规则不会复制进审核副本
  （copy_formula_ranges 只拷公式区域值、不拷 CF 规则），故条件格式提取不扫模板。
- colorScale / dataBar / iconSet 需真实渲染器，仅 Windows/Excel/WPS COM 支持；
  Linux 下不产出。
