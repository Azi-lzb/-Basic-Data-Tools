# 统信原生版实机验收清单

先进入 `uos_audit` 虚拟环境，确认：

```bash
soffice --version
python run.py --check-engine
python run.py --flet
```

## 审核主流程

1. 选择与 Windows 相同的源数据、模板、外部文件与输出目录；
2. 运行“汇总核查表校验”；
3. 核对每个 `_审核版.xlsx`：外部表存在、公式已复制、原始文件未修改；
4. 与 Windows 输出逐条对比：工作簿名、工作表名、定位单元格、错误类型、校验指标、当前值、对比值、差值、描述；
5. 再运行一次，确认“历史校验说明、审核意见”能带回。

## 汇总与合并

1. 运行“汇总校验结果说明”，核对相同工作表名汇总到对应输出工作表；
2. 检查任意行汇总、固定行汇总的多行表头、全局单元格区域、单元格区域；
3. 运行“汇总表合并”，确认只在表头相同时合并；
4. 运行“组合联合核查表”及“组合工作表”，核对隐藏表、合并单元格、样式与重名工作表处理；
5. 用“制作联合模板”生成模板副本，检查不存在不应保留的外部工作簿引用。

## 条件格式

1. 安装 `python3-uno` 后运行含“条件格式结果提取”的流程；
2. 确认只扫描 `条件格式区域`，并仅输出实际触发填充的单元格；
3. 对照 Excel/Windows 版，检查“总行条件格式触发”、校验指标、批注描述及填充色。

出现差异时，保留输入模板、审核副本、运行日志和 LibreOffice 版本号；不要覆盖 Windows 输出，便于逐项定位公式兼容性。
