# 基础数据审核工具

用于批量审核金融机构报送的 `.xlsx` 数据。程序不修改原始报送文件；所有公式、外部工作表和审核导航均写入“审核版”副本。

工作台右上角的“📕 使用说明”打开 Word 文档
`基础数据审核工具使用说明.docx`。本 README 保留项目维护和快速查阅内容。

## 日常使用

1. 双击 `基础数据审核工具.exe`。
2. 选择源数据目录；输出目录默认创建为 `源数据目录\审核结果`。
3. 确认模板目录和自动推荐的模板。需要公式引用外部数据时选择外部文件。
4. 点击对应流程按钮，例如“汇总核查表校验”。
5. 在输出目录查看“机构审核副本”、本期审核结果和运行日志。

运行记录显示时间戳和本次耗时。源数据目录混有多类报表时，应取消勾选不属于本次审核的文件。

### 递归子文件夹怎么用

- **汇总核查表校验**：通常不勾选。源数据目录一般就是本期同类报送文件所在目录，避免把下级目录中的其他文件一并纳入审核。
- **汇总校验结果说明**：机构报送说明按机构分别放在子文件夹时，勾选“递归子文件夹”，再执行汇总。程序会向下查找 `.xlsx` 文件，并跳过工具生成的审核结果目录。

## 三张配置表

配置文件为 `data/config.xlsx`。日常维护只使用以下三张表：

| 工作表 | 作用 |
|---|---|
| 模块化功能 | 定义模块及默认参数，例如“公式校验复制”使用“校验区域”。 |
| 执行流程 | 按顺序组合模块，决定一个按钮实际做什么。 |
| 自定义按钮 | 将“按钮名称”绑定到“流程名称”，并控制是否显示。 |

“本期审核结果”和“历史审核结果”使用完全相同的表头：工作簿名、工作表名、定位单元格、错误类型、校验指标、描述、当前值、对比值、差值、规则编号、历史校验说明、审核意见。公式建议使用最简格式“错误类型｜校验指标｜描述”；需要展示取值时使用“错误类型｜校验指标｜描述｜当前值｜对比值｜差值”。当前值、对比值和差值均可为文字或数字。规则编号按“工作簿｜工作表｜公式单元格｜校验指标”生成，不再附加序号。同一规则可以在“历史审核结果”中保留多行人工说明和审核意见，程序会合并带入本期结果。完成本期审核后，可把需要保留的整行复制到“历史审核结果”。程序只读取历史表并按规则编号预填说明和意见，不会自动写入或覆盖历史表。

复制后可在工作台点击“整理历史规则编号”。它会将同一工作簿、工作表、公式单元格和校验指标下、描述不同但序号冲突的记录整理为 `｜1`、`｜2`、`｜3`；已有不冲突的编号、历史校验说明和审核意见不会改动。

### 模块化功能

固定列：`功能名、功能类型、命名区域名、是否限定工作簿、工作簿关键字、备注`。

常用功能类型统一为：检查_命名区域存在性、核对_表结构比对、修改_外部文件添加、修改_公式校验复制、汇总_公式校验结果提取、汇总_任意行汇总、汇总_固定行汇总、汇总_汇总表合并。

命名区域由模板的名称管理器维护。公式校验复制通常使用 `校验区域`；表结构比对只使用 `表结构区域` 及其下划线后缀变体，并对其中非空单元格做严格值比对，默认至少达到 90% 命中率。任意行汇总填写 `任意行汇总区域`，固定行汇总填写 `固定行汇总区域`；程序自动读取同一工作表的 `表头区域`。

任意行汇总、固定行汇总按来源工作表名称归并，例如所有“任务说明”只进入结果中的“任务说明”工作表。“汇总表合并”不使用命名区域，读取每个源工作簿的所有非空工作表；只有表头逐列一致的工作表才合并，不一致的表头分别保留在同一结果工作簿的不同工作表中。

如需把机构名称、数据日期等固定单元格补充到每一条汇总明细，在名称管理器中将该单元格命名为 `单元格区域.字段名`，例如 `单元格区域.数据日期`、`单元格区域.机构名称`。句点后的文字就是汇总结果列名；这些值会自动重复写入该工作表产生的每一行明细。多个主区域可用 `、`、`，`、`,` 或 `;` 分隔。

`全局单元格区域.字段名` 对所有汇总工作表生效，包括该单元格所在的工作表。它始终单独新增一列；即使与汇总表头同名也允许重复，原表字段和值不覆盖。运行日志会提示产生的同名全局字段列。

### 执行流程

固定列：`流程名、顺序、功能名、启用、失败后处理、是否输出结果、输出文件名、处理对象、备注`。

同一流程按“顺序”执行启用模块。默认“汇总核查表校验”为：检查校验区域 → 检查表结构区域 → 表结构比对 → 外部文件添加 → 公式校验复制 → 校验结果提取；“汇总校验结果说明”为：检查表结构区域 → 检查汇总区域 → 表结构比对 → 任意行汇总。表结构不匹配的单个文件会跳过，运行日志会列明原因。程序使用已选择的模板，不会在流程开始时重新推荐、匹配或切换模板。

“合并同机构多表”是独立准备流程：递归读取源目录，以文件名主名下划线的第一段作为机构名称，将同一机构的多个工作簿合并为一本。每张工作表改名为“表格类型_原工作表名”，重名自动追加序号。合并后需在新工作簿上重新定义命名区域并制作模板，再运行普通审核流程；跨工作簿外部引用不会自动改写。

每次流程运行都会生成一份运行日志 `流程名_运行日志_时间戳.xlsx`（永远生成，失败时也写已收集的部分日志便于排错），一个功能一个工作表：检查类列出各命名区域所在工作表与覆盖区域，表结构比对列出各文件匹配结果，外部文件添加 / 公式校验复制列出复制记录，校验结果提取列出本期问题，另有模板体检工作表。

“失败后处理”填写“停止”时，模块出错即终止流程；填写“跳过”时，记录该模块错误后继续尝试该文件的后续模块（若后续模块依赖前一步，其自身仍可能失败）。“是否输出结果”只对会产出实际文件的功能生效：外部文件添加=阶段副本目录、公式校验复制=审核副本目录、校验结果提取=本期审核结果工作簿，统一命名为 `序号_功能名_时间戳`；“输出文件名”列（可选）可为某步骤指定名字，填写后该步骤输出文件/目录改为 `输出文件名_时间戳`（默认配置把两个流程的最终结果预填为流程名）。“处理对象”列（可选）声明本步骤读哪份数据：留空=源数据目录的文件；填流程中排在前面的功能名，则读该功能产出的副本（例如校验结果提取填“公式校验复制”读套了公式的审核副本，填“外部文件添加”读加了外部表的副本；任意行/固定行/汇总表合并填“公式校验复制”可对审核副本做汇总）。主流程的校验结果提取预填“公式校验复制”、公式校验复制预填“外部文件添加”。处理对象只认流程中排在前面的外部文件添加/公式校验复制等会产副本的功能；引用不匹配或不产副本的功能（如检查类、核对类）时，自动跳过非副本功能，兜底到最近前一个产副本功能（之前没有则兜底到源数据目录），并在运行日志给出提示，不会中断流程。填“否”时这些中间文件处理完即清理。检查类与表结构比对始终只记入运行日志，不受此列影响。每个流程至少应有一个启用步骤填“是”。生产流程通常仅最后的汇总类模块填“是”。

### 自定义按钮

固定列：`按钮名称、流程名称、是否显示、备注`。

“是否显示”填“是”时，工作台显示该按钮；点击后执行同名流程。

## 外部文件

外部文件用于模板的 `INDEX`、`VLOOKUP`、`INDIRECT` 等跨表公式。程序在复制公式前，将需要的外部工作表复制到审核副本；源文件和外部文件均保持不变。外部表与报送文件同名时任务会明确失败，避免覆盖。

## 输出

- `<原文件名>_审核版.xlsx`：可回到公式单元格复核。
- `基础数据审核结果_*.xlsx`：本期审核结果。
- `流程名_运行日志_时间戳.xlsx`：每次流程运行都生成，一个功能一个工作表（检查类列命名区域、表结构比对列匹配结果、外部文件添加 / 公式校验复制列复制记录、校验结果提取列本期问题，另有模板体检）。
- `序号_功能名_时间戳`（填写“输出文件名”列时改为 `输出文件名_时间戳`）：仅当执行流程相应步骤“是否输出结果=是”时生成：外部文件添加=阶段副本目录、公式校验复制=审核副本目录、校验结果提取=本期审核结果工作簿。

“汇总校验结果说明”流程的汇总结果文件名为 `汇总校验结果说明_时间戳.xlsx`（由该步骤“输出文件名”列预填流程名；“是否输出结果=是”决定是否生成；留空时回退为 `序号_任意行汇总_时间戳.xlsx`）。

## 初始化配置

当默认模块或流程被误删时，使用工作台“初始化配置”或运行：

```powershell
基础数据审核工具.exe --init-config
```

初始化只补齐缺失默认模块和流程；如仍为旧版“历史审核记录”，会改名并转换为“历史审核结果”，保留已有的历史校验说明和审核意见。

## 运行条件

Windows 10/11、Microsoft Excel 和 Edge WebView2 Runtime。完整审核使用 Excel 复制和重算公式；文件识别、结构比对和汇总尽量使用 `openpyxl`，以减少低配置电脑的等待时间。
